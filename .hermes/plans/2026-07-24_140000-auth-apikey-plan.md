# Plan d'implémentation — Authentification API Key + Rôles (v2)

> **Pour Hermes :** Utiliser `subagent-driven-development` pour implémenter ce plan tâche par tâche après validation du user.

**Goal :** Ajouter une couche d'authentification par API key statique et 3 rôles utilisateurs (commerçant, responsable logistique, employé) sur le module de gestion de stock existant. L'inscription initiale d'un commerçant reste publique.

**Architecture :** Header `X-API-Key` obligatoire sur tous les endpoints protégés. Table SQLModel `Utilisateur` liée à `Commercant`. Dépendance FastAPI `get_current_user` qui vérifie la clé et retourne l'utilisateur. Permissions vérifiées route par route.

**Tech Stack :** Même stack (FastAPI + SQLModel + SQLite). Pas de JWT, pas de refresh, pas de hashing complexe pour ce MVP.

---

## Contexte et contraintes

- API key statique générée automatiquement à la création d'un utilisateur (UUID4).
- Pas de regénération de clé dans ce MVP.
- 3 rôles :
  - `commercant` : admin de son tenant. Tout CRUD + gestion des utilisateurs.
  - `responsable_logistique` : lecture/écriture stock (produits, entrepôts, mouvements, transferts, alertes). Pas de gestion utilisateurs.
  - `employe` : saisie uniquement (créer mouvements et transferts, lire produits/entrepôts/alertes). Pas de modification/suppression.
- La création de commerçant `POST /commercants/` reste publique (inscription).
- L'endpoint `GET /health` reste public.

### Task 2 : Module d'authentification

**Objective :** Créer les dépendances FastAPI pour vérifier l'API key et les rôles.

**Files :**
- Créer : `src/gestion_stock/auth.py`

**Step 1 :** Écrire `src/gestion_stock/auth.py`

```python
import uuid
from typing import Optional

from fastapi import Depends, Header, HTTPException, status
from sqlmodel import Session, select

from gestion_stock.database import get_session
from gestion_stock.models import Commercant, RoleUtilisateur, Utilisateur


def generate_api_key() -> str:
    return str(uuid.uuid4())


def get_current_user(
    x_api_key: Optional[str] = Header(default=None, alias="X-API-Key"),
    session: Session = Depends(get_session),
) -> Utilisateur:
    if not x_api_key:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Header X-API-Key manquant",
        )
    user = session.exec(select(Utilisateur).where(Utilisateur.api_key == x_api_key)).first()
    if not user or not user.actif:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="API key invalide",
        )
    return user


def require_role(*roles: RoleUtilisateur):
    def checker(user: Utilisateur = Depends(get_current_user)):
        if user.role not in roles:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail="Rôle insuffisant",
            )
        return user
    return checker


def verifier_acces_tenant(user: Utilisateur, commercant_id: int) -> None:
    if user.commercant_id != commercant_id:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Accès interdit à ce tenant",
        )
```

### Task 3 : Endpoint création d'utilisateurs

**Objective :** Permettre au commerçant de créer des utilisateurs pour son tenant.

**Files :**
- Modifier : `src/gestion_stock/routers/commercants.py`

**Step 1 :** Ajouter dans `commercants.py`

```python
from gestion_stock.auth import generate_api_key, get_current_user, require_role, verifier_acces_tenant
from gestion_stock.models import Utilisateur, RoleUtilisateur


@router.post("/{commercant_id}/utilisateurs", response_model=dict, status_code=status.HTTP_201_CREATED)
def create_utilisateur(
    commercant_id: int,
    nom: str,
    email: Optional[str] = None,
    role: RoleUtilisateur = RoleUtilisateur.EMPLOYE,
    user: Utilisateur = Depends(require_role(RoleUtilisateur.COMMERCANT)),
    session: Session = Depends(get_session),
):
    verifier_acces_tenant(user, commercant_id)
    api_key = generate_api_key()
    new_user = Utilisateur(
        commercant_id=commercant_id,
        nom=nom,
        email=email,
        role=role,
        api_key=api_key,
    )
    session.add(new_user)
    session.commit()
    session.refresh(new_user)
    return {
        "id": new_user.id,
        "commercant_id": new_user.commercant_id,
        "nom": new_user.nom,
        "email": new_user.email,
        "role": new_user.role.value,
        "api_key": new_user.api_key,
    }
```

def test_produit_sans_api_key_refuse(client, commercant):
    response = client.get(f"/commercants/{commercant['id']}/produits/")
    assert response.status_code == 401


def test_employe_ne_peut_pas_creer_produit(client, commercant):
    # créer un employé
    emp_resp = client.post(
        f"/commercants/{commercant['id']}/utilisateurs",
        headers={"X-API-Key": commercant["api_key"]},
        json={"nom": "Employé", "role": "employe"},
    )
    emp_key = emp_resp.json()["api_key"]
    response = client.post(
        f"/commercants/{commercant['id']}/produits/",
        headers={"X-API-Key": emp_key},
        json={"sku": "EMP-001", "libelle": "Test"},
    )
    assert response.status_code == 403


def test_acces_tenant_etranger_refuse(client, commercant):
    autre = client.post("/commercants/", json={"nom": "Autre"}).json()
    response = client.get(
        f"/commercants/{autre['id']}/produits/",
        headers={"X-API-Key": commercant["api_key"]},
